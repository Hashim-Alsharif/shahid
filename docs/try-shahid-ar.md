# تجربة شاهد بالعربية والإنجليزية

المفتاح واسم Nemotron محفوظان محليًا في .env. لا تصوّر هذا الملف.
النموذج المعتمد لهذه النسخة هو `nvidia/nemotron-3-super-120b-a12b`، بعد
مقارنة صياغة العربية مع Lightning. أسماء النماذج تظهر في المعاينة والنتيجة.

## فتح التطبيق

إذا كان الخادم يعمل بالفعل افتح http://127.0.0.1:8010/ واضغط Ctrl+F5.
إذا كان متوقفًا، افتح PowerShell ونفّذ:

```powershell
Set-Location -LiteralPath "C:\Users\Hashim Alsharif\Desktop\Hackathons\Nebius & NVIDIA Global"
.\.venv\Scripts\python.exe -m uvicorn app.main:app --host 127.0.0.1 --port 8010
```

اترك PowerShell مفتوحًا. إذا ظهرت رسالة أن المنفذ مستخدم، يوجد خادم يعمل
بالفعل؛ افتح الصفحة بدل تشغيل نسخة أخرى. لإعادة تشغيل نسخة قديمة، أوقفها
باستخدام Ctrl+C في نافذتها أولًا ثم شغّل الأمر.

## التجربة العربية

1. اضغط العربية أعلى الصفحة.
2. اختر «محاولات دخول متكررة»؛ العينة مصطنعة.
3. اضغط «حلّل السجل محليًا». سيظهر 8 طلبات ومصدر واحد وملاحظة واحدة.
   لا يُستدعى النموذج في هذه الخطوة.
4. انزل إلى «اشرح الملاحظات باستخدام Nemotron».
5. اضغط «راجع البيانات قبل الإرسال». سترى JSON فيه معرّفات مثل source-1
   وL0001. هذه المعاينة لا تستهلك توكنات.
6. راجع البيانات. رغم حذف IP ومعاملات URL والإحالات وUser-Agent، تبقى
   الأوقات والمسارات وقد تحمل بيانات حساسة في سجل حقيقي.
7. فعّل خانة الموافقة ثم اضغط «أرسل وفسّر بالعربية». يُرسل طلب واحد
   حقيقي إلى Nebius Token Factory ويستهلك الرصيد. لا توجد إعادة تلقائية.
8. انتظر ظهور «وصل تفسير Nemotron وتم فحص مراجعه». يظهر اسم النموذج
   والتوكنات والمدة، ثم التفسير والبدائل والمعلومات الناقصة وخطوات المراجعة.
9. اضغط رقم دليل داخل بطاقة التفسير، مثل L0001. ستنتقل إلى السطر نفسه
   ويُميّز لونه. رقم الدليل يعود إلى موضع السطر الأصلي في الملف.

## التجربة الإنجليزية

1. اضغط English أعلى الصفحة؛ يتغير اتجاه الصفحة إلى اليسار وتترجم النصوص
   والملاحظات المحلية. تُمسح المعاينة والموافقة والتفسير السابق من العرض.
   تغيير اللغة وحده لا يستدعي النموذج.
2. النتيجة المحلية تبقى متاحة. اضغط Review data before sending.
3. راجع المعاينة وفعّل الموافقة، ثم Send and explain in English.
4. هذا طلب جديد مدفوع بالتوكنات. ستحصل على تفسير باللغة الإنجليزية مع
   روابط الدليل نفسها. اختيار اللغة يُحفظ في هذا المتصفح فقط.

## حدود مقصودة

- التحليل المحلي: حتى 100 KB. الذكاء الاصطناعي: حتى 80 حدثًا و8 ملاحظات
  و32 KB من البيانات المهيأة. لا نرسل مقتطفًا مبتورًا بدون توضيح؛ نرفض الحجم الزائد.
- المعاينة صالحة عشر دقائق ولمرة واحدة. بعد الخطأ أو تغيير البيانات/اللغة
  أو إعادة تشغيل الخادم اطلب معاينة جديدة قبل الإرسال.
- أي رد ناقص أو ذو مراجع غير صالحة يُرفض. قد يستهلك الطلب رصيدًا رغم الرفض.
- فحص المراجع لا يثبت صحة كلام النموذج؛ القصد والاختراق لا يُحسمان من access logs.
- هذا خادم محلي، ولم يُجهز بعد للنشر العام أو استقبال مستخدمين متعددين.

اختبارات المطور المحلية، بدون استدعاء مدفوع:

```powershell
.\.venv\Scripts\python.exe -m pytest -q -p no:cacheprovider
```
